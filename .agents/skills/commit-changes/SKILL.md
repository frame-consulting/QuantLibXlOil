---
name: commit-changes

description: Commit untracked changes to the project. Use this skill when asked to commit modifications to the QuantLibXlOil project.

---

Use the following commands to identify files with untracked changes in the project:

```bash
git diff --name-only
```

Use the following command to read the actual changes to the files with untracked changes:

```bash
git diff
```

Summarize the changes to the files with untracked changes and store the summary in a temporary text file `.git/changes.txt`. The summary must follow this exact format:

```
<one-line summary, max 80 characters>

  - <file>:
    <description starting with capital letter, 4 characters indent, max 80 characters>
    <continuation line if needed, 4 characters indent, max 80 characters>
  - <file>:
    <description>

<a note that the summary was generated by an AI agent and the name of the agent that generated it>
```

Formatting rules:
- Subject line: One line, max 80 characters, no period at end
- Blank line after subject
- Bullet points: Start with `  - ` (two spaces, hyphen, space)
- Continuation lines: Indent with 4 spaces to align with text after bullet
- All lines max 80 characters
- Descriptions: Start with capital letter, no period at end
- Blank line before attribution
- Attribution: text as shown above

Stage all files with untracked changes using the following command:

```bash
git add .
```

Create a git commit with the message from `.git/changes.txt` in the commit message.

Delete the temporary text file `.git/changes.txt` after the commit is created.
