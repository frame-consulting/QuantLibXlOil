# Documentation

This file specifies documentation generation.

Documentation is generated by means of `sphinx`, `myst-parser` for markdown pages and `furo` Sphinx theme.

The documentation contains an auto-generated function index source file [50_api_reference.md](source/50_api_reference.md). The file is generated via the script [make_function_indxed.py](tools/make_function_indxed.py).

Generate the index source file and build the html documentation via

```
make.bat html
```
